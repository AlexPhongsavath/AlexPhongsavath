## Projects

### 🛰️ [LoRa P2P Water Level Monitor](https://github.com/AlexPhongsavath/Heltect_LoRaP2P_For_WaterLevel)
Point-to-point LoRa wireless communication between two Heltec ESP32 boards for real-time water level sensing. Uses an ultrasonic sensor with Modbus and an OLED display to show readings without any internet connection.

`C++` `ESP32` `LoRa` `PlatformIO` `Ultrasonic Sensor`

---

### 🗑️ [What We Waste — Flutter App](https://github.com/AlexPhongsavath/Flutter_What_We_Waste)
A cross-platform Flutter app for tracking and categorizing waste. Built as a university final project with a clean Material Design UI and support for multiple product types and environmental info.

`Flutter` `Dart` `Material Design` `Cross-platform`

---

### 🌱 [IoT Smart Backyard — CEIT](https://github.com/AlexPhongsavath/CEIT_IOT_BACKYARD)
An ESP32-based smart garden system built for a Computer Engineering course at the National University of Laos. Monitors temperature, humidity, soil moisture, and light level via DHT22, soil moisture sensor, and LDR sensor.

`C++` `ESP32` `DHT22` `Soil Moisture` `LDR` `PlatformIO`
